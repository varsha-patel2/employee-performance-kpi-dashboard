# Employee Performance KPI Dashboard

A C-based application for monitoring and analyzing employee performance Key Performance Indicators (KPIs).

## Features
- Track employee performance metrics and KPIs
- Automated build setup using Makefile
- High-performance C implementation

## Building the Project

To build the executable, run:
```bash
make
```

To clean build artifacts, run:
```bash
make clean
```

## Requirements
- GCC compiler (C11 support)
- Make
